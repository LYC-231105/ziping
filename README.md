# 子平研习

本机运行的子平八字文化研习网页，分为八字排盘、八字详批、子平学堂三个独立入口。

当前包含78讲原创课程、男女取法专题、身强身弱证据练习、前八步大运及逐年条件研读、本机版七部古籍离线阅读和整盘实训。

## 打开网页

直接打开 `index.html`，或安装 Node.js 20以上后双击 `启动网页.cmd`。也可运行：

```sh
npm start
```

程序计算在本机完成，未连接外部大模型。出生资料、收藏和学习进度保存在使用者浏览器中。

## 检查

```sh
npm test
```

测试验证程序计算、规则表、流年时间分段与课程引用，不验证命理预测人生的效果。古籍为网络整理本，保留来源和待校勘状态；课程及复杂解释尚待师资复审。疾病、寿命、固定财富金额、婚育事件不能凭本程序核实。第三方历法库许可保留在 `vendor/lunar.LICENSE`。

## 更新 GitHub

固定仓库：`https://github.com/LYC-231105/ziping`，默认分支 `main`。

以后修改本项目后，双击 `上传GitHub.cmd`，或运行：

```powershell
.\upload-github.ps1
```

上传采用完整版本同步：新增文件上传，同名文件覆盖更新，本地删除的项目文件同步从仓库删除。远端已有其他文件时以当前本地版本为准。每次保存为新提交，历史版本继续保留；不需要手动删除旧文件或强制推送。

需要本机 Git 已登录具有仓库写权限的 GitHub 账号。若权限或仓库保护规则拒绝上传，脚本会明确报错，不会假报成功。此入口仅同步代码，不自动部署网站。

项目执行规则见 `AGENTS.md`，详细使用说明见 `使用说明.md`。


## 公开仓库中的书库范围

公开仓库保留书目、来源与原文定位规则。当前七部网络整理本尚未确认其具体版本的公开再分发条件，因此全文文件 `books/BK*.js` 和索引 `private/passages.jsonl` 留在本机，不随 GitHub 上传。只克隆公开仓库时，排盘、详批、78讲教学和实训可用，离线全文阅读与原文检索需要另外放入具备合法使用权限的对应语料。

这项排除不删除本机书库，也不影响已运行的D盘网页。后续只有在相应版本的公开条件明确后，才逐本纳入仓库。来源检查见 `references/GitHub公开范围与来源核验.json`。
